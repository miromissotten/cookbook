Below, you can find a flow chart to easily construct a nice bowl.
This is a high level scheme. For more information on each component, the following pages will help.

```mermaid
flowchart TD
    Start([Start Building Ramen Bowl])

    %% 1. Broth
    Start --> BrothSelect{Select Broth}
    BrothSelect --> B_Clear[Japanese Clear Broth]
    BrothSelect --> B_Tonkotsu[Tonkotsu]
    BrothSelect --> B_French[French Broth]

    %% 2. Tare
    B_Clear --> TareSelect
    B_Tonkotsu --> NoodleSelect
    B_French --> TareSelect

    TareSelect{Select Tare}
    TareSelect --> T_Shio[Shio]
    TareSelect --> T_Shoyu[Shoyu]
    TareSelect --> T_Miso[Miso]

    %% 3. Noodles
    T_Shio --> NoodleSelect{"Which noodles do you want?"}
    T_Shoyu --> NoodleSelect
    T_Miso --> NoodleSelect

    NoodleSelect --> N_ramen[Ramen Noodles]
    NoodleSelect --> N_udon[Udon Noodles]
    NoodleSelect --> N_soba[Soba Noodles]

    %% 4. Toppings (Exactly 4)
    N_ramen --> Topping_Proteinchoice{Optional: Do you want a protein? Choose one.}
    N_udon --> Topping_Proteinchoice
    N_soba --> Topping_Proteinchoice
	

    Topping_Proteinchoice --> P_Chashu[Chashu]
    Topping_Proteinchoice --> P_Chicken[Chicken]
    Topping_Proteinchoice --> P_Beef[Beef Strips]
    Topping_Proteinchoice --> P_Vegan[Vegan Chashu]

    P_Chashu --> Topping_VegChoice{"Select other toppings<br/>(4 is a good number in total)<br/>(4 incl the protein if chosen)"}
	P_Chicken --> Topping_VegChoice
	P_Beef --> Topping_VegChoice
	P_Vegan --> Topping_VegChoice

    Topping_VegChoice --> V_Spicy[Spicy]
    Topping_VegChoice --> V_Smoky[Smoky]
    Topping_VegChoice --> V_Sweet[Sweet]
    Topping_VegChoice --> V_Fermented[Fermented]
    Topping_VegChoice --> V_Bright[Bright]
    Topping_VegChoice --> V_Savoury[Savoury]
    Topping_VegChoice --> V_Crunchy[Crunchy]

    %% 5. Fat (Applied on Top)
    V_Spicy --> Assemble[Assembled Bowl Base]
    V_Smoky --> Assemble
    V_Sweet --> Assemble
    V_Fermented --> Assemble
    V_Bright --> Assemble
    V_Savoury --> Assemble
    V_Crunchy --> Assemble

    Assemble --> FatSelect{Apply Finishing Fat On Top}

    FatSelect --> F_Oil[Aromatic Oil]
    FatSelect --> F_Butter[Butter]
    FatSelect --> F_None[No Added Fat]

    F_Oil --> End([Finished Ramen Bowl])
    F_Butter --> End
    F_None --> End
```
