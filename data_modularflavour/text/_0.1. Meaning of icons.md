At the moment of writing, I'm converting to vegan, so most recipes are vegan or have a vegan option. It's always indicated with the icons. Below, all icons used in the recipes are explained and can be used to create dishes according to your dietary wishes.

| Icon                            | Meaning                                                                                                                          |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| ![[icon_component.png\|50]]     | This recipe is for the creation of a component to use in the creation of dishes.                                                 |
| ![[icon_dish.png\|45]]          | This recipe is for the creation of a complete dish.                                                                              |
| ![[icon_glutenfree.png\|45]]    | This recipe is gluten free.                                                                                                      |
| ![[icon_lactosefree.png\|40]]   | This recipe is lactose free.                                                                                                     |
| ![[icon_vegetarian.png\|27]]    | This recipe is vegetarian.                                                                                                       |
| ![[icon_vegan.png\|40]]         | This recipe is vegan.                                                                                                            |
| ![[icon_FoodForDating.png\|50]] | This recipe is suitable for a date night where you want to impress without wasting time that could be spent in eachother's arms. |
| ![[icon_love.png\|30]]          | This recipe is a favourite of Miró. *(If so, it is printed behind the page number of the recipe's first sheet.)*                 |
| ![[icon_difficulty_2.png\|56]]  | This recipe has a difficulty rating of two out of three.                                                                         |
| ![[icon_freezable.png\|29]]     | This recipe can be stored in the freezer once made.                                                                              |

If the icon is greyed out, there are options to make it glutenfree/lactosefree/vegetarian/vegan, but at base, it is not.
